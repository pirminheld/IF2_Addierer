# IF2 – Halb- und Volladdierer

Interaktive Einführung für eine 45-Minuten-Stunde. Einstieg, Halbaddierer, Volladdierer aus zwei Halbaddierern und ODER, Selbsttest.

Offline: index.html per Doppelklick öffnen. Alle Assets sind lokal; keine externen Bibliotheken, Tracker oder Schriftarten.

Online: https://pirminheld.github.io/IF2_Addierer/

Unterricht: Einstieg gemeinsam (5–8 Min.), Halbaddierer untersuchen (10–12 Min.), Volladdierer und Übertrag (15 Min.), Selbsttest und Sicherung. Kein BCD-Rechnen.
